# Changelog

## 0.17.5

- Команды запуска («Запустить Предприятие», «Открыть Конфигуратор»,
  «Загрузить изменённые объекты», «Загрузить + обновить БД», «Обновить
  конфигурацию БД») больше не требуют ручного `.vscode/tasks.json`.
  Если в воркспейсе нет задачи с ожидаемым именем, расширение само
  запускает соответствующий `.1С/*.ps1`-скрипт напрямую — `tasks.json`
  остаётся опциональным удобством, а не обязательным условием для работы
  кнопок в дереве.
