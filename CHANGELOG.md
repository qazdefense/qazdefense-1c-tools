# Changelog

## 0.18.2

- Исправлен запуск базы из списка: платформа получала строку соединения
  целиком и не видела путь («Информационная база не обнаружена! Создать
  новую?»). Теперь файловой базе передаётся путь (`/F`), серверной —
  «сервер\база» (`/S`), веб-базе — адрес (`/WS`). Если каталог файловой
  базы недоступен, расширение скажет это сразу, не запуская клиент.

## 0.18.1

- Вкладка «1С» переименована в «1С: базы» и теперь показывает два списка.
  Новый список **«Базы 1С»** — обычные базы этой машины из `ibases.v8i`
  (тот же список, что в окне запуска 1С), с папками и вложенностью. Открытый
  проект для него не нужен: кнопки в строке запускают Предприятие и
  Конфигуратор, клик по базе открывает панель базы — запуск, каталог базы,
  строка соединения, выбор версии платформы и кнопка «Завести профилем
  проекта» (путь, сервер и платформа подставляются сами).
  Прежний список профилей репозитория остался и называется «Базы проекта».
- Платформа 1С определяется сама: все версии из `Program Files\1cv8` с
  выбором подходящей по версии базы. Путь можно задать вручную настройкой
  `qazdefense1c.platformPath`, дополнительные списки баз —
  `qazdefense1c.basesListFiles`.
- Команда **«1С: Настройка расширения»** открывает мастер: по шагам видно,
  что уже найдено (платформа, базы, проект, профили, выгрузки конфигураций),
  чего не хватает и что нажать, чтобы это исправить. Необязательные шаги
  помечены отдельно. При первой установке расширение предлагает открыть
  мастер один раз.
- Те же задачи (Предприятие, Конфигуратор, деплой, обновление БД) продублированы
  панелью «Задачи» во вкладке «1С: базы» — запуск там же, где выбирают базу;
  индикация выполнения общая с вкладкой «1С: проект».
- Мастер настройки открывается повторно: шестерёнка в заголовке любой панели
  вкладки «1С: базы» или команда «1С: Настройка расширения».
- В «Начале работы» VS Code появился раздел «1С QazDefense Tools: первые
  шаги» с теми же четырьмя шагами.

## 0.17.6

- На странице расширения появились ссылки на исходный код на GitHub и на
  Marketplace.

## 0.17.5

- Команды запуска («Запустить Предприятие», «Открыть Конфигуратор»,
  «Загрузить изменённые объекты», «Загрузить + обновить БД», «Обновить
  конфигурацию БД») больше не требуют ручного `.vscode/tasks.json`.
  Если в воркспейсе нет задачи с ожидаемым именем, расширение само
  запускает соответствующий `.1С/*.ps1`-скрипт напрямую — `tasks.json`
  остаётся опциональным удобством, а не обязательным условием для работы
  кнопок в дереве.
