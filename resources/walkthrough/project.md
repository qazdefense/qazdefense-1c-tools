# Подключить проект

Проект нужен, когда конфигурация выгружена в XML и лежит в репозитории: тогда
становятся доступны задачи запуска и деплоя и дерево метаданных.

Ожидаемая структура:

```
Configurations/<База>/Configuration      выгрузка конфигурации (DumpConfigToFiles)
Configurations/<База>/Extensions/<Имя>   выгрузки расширений
.1С/base-profiles/*.psd1                 профили баз
.1С/switch-base.ps1, deploy-to-ib.ps1    скрипты переключения и деплоя
```

Профиль базы заводится кнопкой **+** в панели «Базы проекта» либо из панели
любой базы списка 1С — кнопкой «Завести профилем проекта»: путь, сервер и
платформа подставятся сами, останется ввести имя латиницей.
