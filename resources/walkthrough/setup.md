# Проверить настройку

Мастер настройки показывает по шагам, что уже готово, а чего не хватает:

- **Платформа 1С** — ищется сама в `Program Files\1cv8\<версия>\bin\1cv8.exe`.
  Если платформа стоит в другом месте, путь указывается кнопкой в мастере
  (он сохранится в настройке `qazdefense1c.platformPath`).
- **Список баз 1С** — берётся из `ibases.v8i`, того же файла, что показывает
  окно запуска 1С. Ничего заполнять не нужно: базы появятся сами.
- **Проект, профили баз, выгрузки конфигураций** — необязательные шаги, нужны
  только для деплоя и дерева метаданных.

Пункты со знаком `○` можно пропустить: базы и запуск работают и без них.
