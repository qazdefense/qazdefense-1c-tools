# Посмотреть метаданные

Вкладка **1С: проект** → панель **Метаданные** показывает конфигурацию активной
базы деревом, как в Конфигураторе: справочники, документы, регистры, расширения
и заимствованные объекты — прямо из XML-выгрузки, без запуска Конфигуратора.

Правый клик по объекту:

- **ER-диаграмма объекта** — связи по реквизитам-ссылкам;
- **Визуализация формы** — как форма выглядит, без Конфигуратора;
- **Просмотр макета** — табличный документ;
- **Предопределённые элементы** — список с именами и кодами;
- **Заимствовать в расширение** — черновик объекта в расширении;
- **Фильтр по подсистеме** — оставить в дереве только её объекты.

Если дерево пустое — конфигурация ещё не выгружена в
`Configurations/<База>/Configuration`.
